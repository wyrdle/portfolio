WIP Night

Event Graphics

Summary: WIP Night is an event series where Sydney game developers share their work-in-progress games with the public through microtalks and games showcases. I was responsible for the event graphics and printer phamplets/zines.

Event Graphics / Social Posts

There have been several WIP Night events since 2023, and some variations for Pride Month and Women's Day. As such, the graphics for WIP Night have regularly been adjusted to fit the theme and sponsor demands. They have all been resized for posting on X, Bluesky, Instagram and LinkedIn.

Event phamplets and Zines

For several of the WIP Nights, we had phamplets showcasing the various games showcasing on the night. These became more complex and detailed as we gained sponsorships and grew in scale.

The WIP Night event landing page.

Landing Page

As WIP Night grew into a regular and sponsored event, we wanted to give it a permanent landing page on our website, that would document its history and impact. I mocked up this layout in Figma before implementing it with HTML and CSS.
